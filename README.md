## Install

1. Download the `.dotx` files.
2. Save them in your personal templates folder:
   - **Windows:** `Documents\Custom Office Templates`
   - **Mac:** `~/Library/Group Containers/UBF8T346G9.Office/User Content/Templates`
3. In Word: **File → New → Personal** (or *Custom*) → choose a template. Double-clicking a `.dotx` also starts a new document from it.

## Filling them in

Everything you need to replace is written as **`[grey italic text in brackets]`**. Use **Ctrl + H → Find `[`** to step through each one, and check none remain before sending.

### Invoice

- **Invoice number** follows the existing scheme: `NDCL` + 3-digit sequence + `/` + client country code, e.g. `NDCL002/UG`.
- Fill **Bill to**, the **payment description**, line items, totals and **amount in words**.
- **Payment details are deliberately left blank.** Add the company bank details once, save your own copy of the template (File → Save As → Word Template), and keep that copy private — never commit bank details to this public repository.
- Export as PDF before sending: **File → Save As → PDF**.

### Proposal

Cover page, contents (right-click → *Update Field*), executive summary, understanding of the assignment, objectives and scope, approach and methodology, deliverables, work plan, team, budget, payment schedule and terms, and an acceptance/signature block. Grey guidance text explains what each section should contain — delete it as you write.

### Letterhead

Page one carries the full letterhead (logo, company name, offices, contacts) and a company-details footer; continuation pages use the compact Neudata header and page numbers.

## Styles

All templates share the same styles, so text pasted between them keeps its look:

| Style | Look |
|---|---|
| Title / Subtitle | Century Gothic, navy / teal |
| Heading 1 | Century Gothic 15 pt navy, teal rule beneath |
| Heading 2 / 3 | Century Gothic, logo blue / teal |
| Normal | Arial 10.5 pt |
| Key Findings | Tinted box with teal left border |
| Tables | Navy header row, light striping, bold total rows |

Colours: teal `#055F56`, navy `#04242F`, logo blue `#0B376C`, mist `#EAF2F5`, grey `#8A99A3`.

## Company details to complete

The company registration number, PIN/VAT number and postal address appear as placeholders in the letterhead and invoice footers. Once confirmed, set them in `build_templates.py` and rebuild so every template carries them.

## Rebuilding

The templates are generated by [`build_templates.py`](build_templates.py) (python-docx) and saved as `.dotx` by Microsoft Word:

```powershell
pip install python-docx
powershell -ExecutionPolicy Bypass -File build.ps1
```
